# OSA Installer — Vendor Assets

Public download hosting for licensed vendor installers (Blackmagic Ultimatte Setup, Supertone Clear) used by the multi-platform installer in [itsarielelise/installer](https://github.com/itsarielelise/installer).

No client configs or business data live here — just the installer binaries themselves, attached as Release assets so they can be downloaded without a GitHub account. See that repo's `docs/ADDING_SOFTWARE.md` for how these are referenced.
